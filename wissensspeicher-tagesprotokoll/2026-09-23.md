## C7 · BERICHTIGUNG zu C5, und ein Fehler, den ich selbst eingebaut habe

**C5 sagt über den Kugelfall, er rufe `zensus_statische_klassen` gar nicht auf, der Zensus habe
„genau zwei Aufrufstellen“. Das ist FALSCH.** Es gibt drei: Kanal, **Kugel** und Nahfeld. Die Kugelstelle
steht hinter einem `alloc_facetten(...)` auf **derselben Zeile**; mein `grep ... | cut -c1-100` hat sie
abgeschnitten, und ich habe die Zeile als reine alloc-Zeile gelesen. Genau die Werkzeugfalle, die im
Merkzettel steht („Konsolen-Umbruch verschluckt grep-Zahlen“) — diesmal hat sie einen Befund erfunden.

**Schlimmer: die Korrektur aus C5 hat dadurch einen stillen Bindungsfehler erzeugt.** Der neue Parameter
`const bool rek_an` steht zwischen `alpha2_an` und `ort`. Die nicht mitgezogene Kugelzeile übergab weiter
neun Argumente, also band **`"Kugel"` (const char*) an `rek_an`** — implizit, immer `true` — und `out_dir`
an `ort`. **`g++ -fsyntax-only` meldete rc=0 und keine Warnung.** Wirkung wäre gewesen: jeder Kugellauf
schreibt Marken, auch bei `CFD_FAC_REK=0`, und alle Zensusmeldungen tragen den Exportpfad als Ortsnamen.

**Strukturfix statt Pflasterfix:** der Parameter ist jetzt ein **starker Typ**,
`enum class RekMarken : bool { aus, an }`. Ein `const char*` konvertiert nicht dorthin.

**Gegentest, gefahren statt behauptet:** in einer Kopie des Baums habe ich das Argument an der Kugelstelle
wieder entfernt. Ergebnis: `error: cannot convert 'const char*' ... ` — **Übersetzungsfehler**. Genau der
Fehler, der vorher stumm durchlief, bricht jetzt den Bau ab. Kopie danach gelöscht (war ein Scratchpad,
keine Laufdaten).

**Lehre, die über diesen Fall hinausgeht:** wer eine Signatur um einen Parameter erweitert, dessen Typ
implizit aus einem benachbarten Argumenttyp entsteht (bool ← const char*, bool ← int, float ← int),
baut eine Falle, die der Übersetzer nicht sieht. **Neue Parameter in diesem Code bekommen einen starken
Typ, oder sie kommen ans Ende ohne Default.** Und: `grep` nach Aufrufstellen NIE mit `cut` abschneiden —
mehrere Anweisungen je Zeile sind in dieser Datei der Normalfall.
